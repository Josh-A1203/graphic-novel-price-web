# Software Requirements Specification (SRS)

## Project Title
Graphic Novel Price Tracker

## Team Members
- Joshua Alcaraz
- Gray Espinoza
- Jairo S.

## Project Description

This project will provide users with the ability to compare graphic novel prices across multiple retailers including Amazon, Barnes & Noble, CGN, and OPB.

The goal is to help users find the best available prices and make informed purchasing decisions.

## Planned Features

- Search graphic novels
- Compare retailer prices
- View MSRP and current prices
- Direct retailer links
- Historical price tracking
- Daily price updates
